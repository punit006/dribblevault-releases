# DribbleVault releases

Signed and notarised installers for **DribbleVault**, a local-first password
manager and encrypted file vault by Dribble Software Private Limited.

The source code is not in this repository. Product page:
https://www.dribblesoft.com/dribblevault

Download from [Releases](https://github.com/punit006/dribblevault-releases/releases).
Every release carries `SHA256SUMS.txt`; check your download with:

    shasum -a 256 -c SHA256SUMS.txt
